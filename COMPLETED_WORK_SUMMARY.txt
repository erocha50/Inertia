KEY FEATURES:
═════════════════════════════════════════════════════════════════════════════════

→ MOMENTUM SCALING
  Speed increases based on current movement speed
  Stationary: 15.0 units/s (minimum)
  Running at max: ~125.0 units/s (with 1.5x multiplier)
  Smooth scaling between speeds

→ INTELLIGENT DIRECTION SYSTEM
  Priority 1: WASD input direction (if player holding keys)
  Priority 2: Current velocity direction (if moving)
  Priority 3: Camera forward direction (if stationary)
  Always goes where player expects

→ ATTACK DURATION
  0.2 second execution window
  Velocity is locked to attack direction
  Can't be canceled mid-attack
  Movement feels committed and powerful

→ COOLDOWN MANAGEMENT
  5.0 second cooldown between attacks
  Prevents spam
  Clear feedback to player
  Tunable in inspector

→ INPUT LOCK
  WASD input ignored during 0.2s attack
  Prevents accidental direction changes
  Makes attack feel solid and intentional

→ CAMERA FEEDBACK
  Camera shake on attack execution
  Intensity based on impact trauma
  Helps convey power and impact
  Integrates with existing camera system

→ SIGNAL SYSTEM
  Emits signal for other systems to react
  Available for audio, animations, VFX
  Architecture supports future expansion

HOW TO USE:
═════════════════════════════════════════════════════════════════════════════════

PLAYING THE GAME:
1. Run the game (F5)
2. Press left mouse button to execute dash attack
3. Attack speed scales based on how fast you're running
4. Wait 5 seconds between attacks (cooldown)

TUNING IN INSPECTOR:
1. Select the Player node in scene
2. Find "Dash Attack" export group
3. Adjust parameters to tune feel:
   • dash_attack_force: Higher = more base speed
   • dash_attack_cooldown: Higher = longer wait between attacks
   • dash_attack_momentum_scale: Higher = more speed bonus from running
   • dash_attack_min_speed: Higher = stronger when standing still

INTEGRATING WITH OTHER SYSTEMS:
1. Listen to "dash_attack_performed" signal:
   ```gdscript
   player.dash_attack_performed.connect(_on_dash_attack)
   func _on_dash_attack():
       # Play sound, trigger animation, apply heat cost, etc.
   ```

2. Access attack direction:
   ```gdscript
   var attack_direction = player._dash_attack_dir
   ```

3. Check if currently attacking:
   ```gdscript
   if player._dash_attack_active:
       # Prevent interactions during attack
   ```
