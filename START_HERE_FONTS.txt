🚀 GETTING STARTED (DO THIS FIRST):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  Download a font you like:
      • Google Fonts: https://fonts.google.com (free, easy!)
      • DaFont: https://www.dafont.com
      • Download any .ttf or .otf file

  2️⃣  Drop it in the fonts folder:
      res://fonts/YourFont.ttf  ← Just copy it here!

  3️⃣  Open the font config:
      In Godot Editor → res://Resources/font_config.tres → Double-click

  4️⃣  Change the font path:
      • Look for "title_font_path"
      • Click the folder icon
      • Select your new font file
      • Save!

  5️⃣  Adjust the size:
      • Change "title_font_size" to whatever looks good
      • Try: 60-80 for big titles

  Done! Your menu now has your custom font! ✨

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


📋 WHAT YOU CAN CUSTOMIZE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Edit these in: res://Resources/font_config.tres

  TITLE FONTS:
    • title_font_path     (font file for big "INERTIA" text)
    • title_font_size     (default: 72, try 60-80)

  BUTTON FONTS:
    • button_font_path    (font for PLAY/SETTINGS/QUIT buttons)
    • button_font_size    (default: 24, try 20-28)

  OTHER:
    • subtitle_font_path & subtitle_font_size
    • status_font_path & status_font_size
    • version_font_path & version_font_size

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💡 TIPS & TRICKS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✓ Use different fonts for different UI elements!
    • Fancy font for title, tech font for buttons = looks cool
    • e.g., Orbitron (title) + JetBrains Mono (buttons)

  ✓ Font sizes matter!
    • Too small = blurry
    • Too big = doesn't fit
    • Start with: title=72, buttons=24, adjust from there

  ✓ Free font sources:
    • Google Fonts (quality fonts, slow download)
    • DaFont (fun fonts, fast download)
    • FontSquirrel (professional, reliable)

  ✓ Performance:
    • Same font used 10 times = loaded once (cached)
    • No performance hit for multiple UI elements

❓ QUICK TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Font not showing?
    → Check path is EXACTLY: res://fonts/YourFont.ttf
    → File must exist in res://fonts/ folder
    → Try a different font to test

  Text looks blurry?
    → Increase font size (smaller = blurry)
    → 10px minimum, 60px+ for titles

  What if I mess up?
    → Edit res://Resources/font_config.tres
    → Change all paths to: res://fonts/BebasNeue-Regular.ttf
    → Reset sizes: title=72, subtitle=16, buttons=24, status=14
